# Tomato Classification Using Deep Learning

## Overview

This project was developed as part of an AEIT group presentation. It explored the use of deep learning and computer vision to classify tomatoes into three categories: raw, ripe, and rotten.

The project involved experimenting with two deep learning architectures, InceptionV3 and ResNet50, to understand how image classification works and compare the models' performance on tomato images.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Scikit-learn
- Jupyter Notebook
- Deep Learning and Computer Vision

## Models and Results

Two models were evaluated on a test dataset of 180 tomato images:

- **InceptionV3:** 90% test accuracy
- **ResNet50:** 40% test accuracy

The results provided an opportunity to compare the performance of different model architectures on the same classification task.

## Learning Experience

This project provided practical exposure to image classification, deep learning models, and model evaluation. It was an introductory exploration of how AI can be applied to a real-world problem, rather than a production-ready tomato sorting system.

The available notebooks focus on evaluating previously saved models rather than training them from scratch.
